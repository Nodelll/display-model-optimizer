# Display Model Optimizer 0.8.0-beta.1 — Fabric ports

Separate **prerelease** builds for **Minecraft 26.2** and **Minecraft 1.21.11**. Download only the JAR matching your game version. The Minecraft 26.3 stable release remains 0.8.0.

| Minecraft | DMO version | Java | Optional API / settings UI |
| --- | --- | --- | --- |
| 26.2 | `0.8.0-beta.1+mc26.2` | **25** | Fabric API **0.161.0+26.2** / Mod Menu **20.0.3** |
| 1.21.11 | `0.8.0-beta.1+mc1.21.11` | **21** | Fabric API **0.141.6+1.21.11** / Mod Menu **17.0.1** |

Both require **Fabric Loader 0.19.5+**. Entity Culling **1.11.3** is optional for occlusion; use its build for the matching game version. Sodium is optional; validation uses **0.9.2** for 26.2 and **0.8.14** for 1.21.11.

- **26.2:** retains the modern model-preparation and draw-group paths; adapts display bounds, resource reload hooks and the FRAPI 14 geometry bridge.
- **1.21.11:** uses a bounded per-frame vanilla model-parts cache during drawing, tags queued display commands, and wraps FRAPI 8 model emission before Indigo/Sodium rendering. The JAR is remapped to intermediary and compiled for Java 21.
- Distance limiting, conservative model-bound culling, optional Entity Culling, settings migration and Mod Menu integration are retained. The default distance is **18 blocks**; set it to **0** to preserve the original game/server range.
- The 1.21.11 pipeline has no matching 26.x draw-group lookup target. That hook is omitted and its advanced settings are hidden.
- Persistent caching preserves the current renderer's lighting, tint, pose and outlines. Dynamic/unknown keys and oversized models bypass caching. Block culling remains conservative when FRAPI geometry has unknown bounds.

Validation covers shared cache/configuration/bounds tests, production-JAR mixin transformation against the actual game classes, Java 21 intermediary names on 1.21.11, optional-dependency absence, real Entity Culling/Indigo/Sodium hooks and actual target-version Sodium mesh replay parity. SHA-256 files accompany both JARs.

These are **prereleases**. No interactive world, shader or Vulkan session was run in the build environment, and **no FPS results are claimed for these ports**. Existing README performance tables apply to Minecraft 26.3.

[Port details, limitations and build instructions](https://github.com/Nodelll/display-model-optimizer/blob/main/ports/README.md)

**По-русски:** это отдельные пре-релизные сборки DMO для **26.2** и **1.21.11**, с учётом различий их рендеринга и API. Для 26.2 нужна **Java 25**, для 1.21.11 — **Java 21**; для обеих — **Fabric Loader 0.19.5+**. Установите только JAR для своей версии игры.

В 1.21.11 кэш подготовки работает на сборе частей модели во время отрисовки, а геометрия кэшируется через FRAPI 8. Оптимизация поиска draw-групп из 26.x в этой версии отсутствует, её настройки скрыты. Для 26.2 адаптированы границы display, обработка перезагрузки ресурсов и FRAPI 14.

Автоматические проверки выполнены на отдельных зависимостях каждой версии. Проверки мира, шейдеров и Vulkan в игре ещё нужны; старые FPS-замеры относятся только к **26.3**. Стабильная 0.8.0 остаётся основным релизом для 26.3.
