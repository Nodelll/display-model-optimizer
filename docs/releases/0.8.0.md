# Display Model Optimizer 0.8.0 — Minecraft 26.3

Stable release for **Minecraft 26.3**, **Fabric Loader 0.19.5+** and **Java 25**.

Adds a bounded **persistent geometry cache for `block_display`**. Supported converted geometry is reused across frames, while each display keeps its current tint, lighting, pose and submission. The cache follows Fabric geometry keys, has entry/quad budgets and invalidates on resource, world, settings and renderer changes. Its independent switch is under **Mod Menu → Advanced**.

The new cache needs optional **Fabric Renderer API 17.0.16+**; other DMO features remain available without it. Entity Culling and Mod Menu remain optional. The default extra display distance remains **18 blocks**; set it to **0** to retain the original range.

Two complete 48-phase runs on **Ryzen 5 5600, RTX 3070 8 GB, 16 GB RAM, 1920 × 1080** measured the same production implementation in **0.8.0-alpha.1**:

| Comparison | Without shaders | Complementary Unbound r5.9.3 — High |
| --- | ---: | ---: |
| Combined DMO, opaque wall | 293.4 → 639.8 FPS (**+118.1%**) | 117.2 → 165.3 FPS (**+41.1%**) |
| Combined DMO, models in front | **+3.8%** | **+2.9%** |
| Geometry cache alone, identical blocks | **+6.1%** | **+2.7%** |
| Geometry cache alone, varied blocks | **+4.7%** | **+3.5%** |
| Geometry cache alone, changing blocks | **+4.6%** | **+3.1%** |

Two 30-second repetitions per mode, ABBA, extra display distance **0** for these comparisons. High preset reported by the tester. Results are specific to this synthetic arena; time/weather were not frozen. In the changing-block shader comparison, mean phase 1% low fell **64.9 → 60.0 FPS**, with long frames coinciding with GC pauses.

Known limits: the per-frame snapshot cache safely bypasses the tested renderer-added state; `block_display` off-screen/occlusion culling is limited on the tested FRAPI/Sodium path because usable model bounds are absent. Such models stay visible. The new cache and the distance limit still work for blocks. Visual correctness with every custom model/shader pack is not established by these tests.

Validation includes **197833 assertions across eight suites**, **129 actual Sodium mesh parity checks**, optional-dependency/Entity Culling mixin transformations, and all ten automatic checks in both submitted in-game runs. The release workflow reruns build and renderer checks before publishing the JAR and SHA-256 file.

Download `display-model-optimizer-0.8.0+mc26.3.jar`, replace the previous DMO JAR in the client `mods` folder and restart Minecraft. DMO Benchmark is a separate testing companion and is not bundled in this release. Remove the Benchmark 1.1.0 helper JAR after the alpha tests: its dependency targets the exact alpha build.

Стабильный **0.8.0** добавляет межкадровый кэш геометрии `block_display`, отдельную настройку и ограничение памяти. Требуется необязательный Fabric Renderer API 17.0.16+; остальные функции работают без него.

В двух полных игровых прогонах новая функция дала **+4,6–6,1% FPS без шейдеров** и **+2,7–3,5% с Complementary Unbound r5.9.3, пресет High**. За непрозрачной стеной совместный эффект DMO составил **+118,1%** и **+41,1%** соответственно. Это результаты конкретного стенда; ограничения кэша на кадр, отсечения блоков и стабильности медленных кадров описаны в README.
