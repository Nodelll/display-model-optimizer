# Display Model Optimizer 0.7.1 — Minecraft 26.3

Fixes the crash when opening DMO settings through **Mod Menu**:

```text
IllegalStateException: Can only blur once per frame
```

Minecraft 26.3 extracts the screen background before the settings content. DMO requested that background a second time; this release removes the duplicate request and retains normal widget rendering.

For **Minecraft 26.3**, **Fabric Loader 0.19.5+** and **Java 25**. This remains an experimental beta. Existing settings, the **18-block** default display range, model caching, off-screen culling and optional Entity Culling integration are preserved.

The release workflow builds from the tagged source and runs all seven automated test suites before publishing the JAR. The GUI regression checks the official Minecraft screen wrapper, reproduces the exact double-blur exception and verifies 128 frame resets. This is an automated regression check, rather than a full graphical client test.

Download `display-model-optimizer-0.7.1+mc26.3.jar`, replace the previous DMO JAR in the client `mods` folder, and restart Minecraft. A `.jar.sha256` asset provides the checksum of the published binary.

Исправлен вылет при открытии настроек DMO через **Mod Menu** с ошибкой:

```text
IllegalStateException: Can only blur once per frame
```

Minecraft 26.3 подготавливает фон до содержимого экрана настроек. DMO повторно запрашивал этот фон; лишний вызов удалён, обычная отрисовка элементов сохранена.

Для **Minecraft 26.3**, **Fabric Loader 0.19.5+** и **Java 25**. Версия остаётся экспериментальной бетой. Существующие настройки, дальность **18 блоков** по умолчанию, кэширование моделей, отсечение вне кадра и необязательная интеграция с Entity Culling сохранены.

Перед публикацией JAR сборка запускает семь автоматических наборов проверок. Новая регрессионная проверка использует официальный порядок подготовки экрана Minecraft, воспроизводит исходное исключение и проверяет сброс состояния в 128 кадрах. Это автоматическая проверка, а не запуск полного графического клиента.

Замените предыдущий DMO JAR в клиентской папке `mods` файлом `display-model-optimizer-0.7.1+mc26.3.jar` и перезапустите игру. Контрольная сумма опубликованного JAR находится в отдельном файле `.jar.sha256`.
