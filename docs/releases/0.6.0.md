# Display Model Optimizer 0.6.0 — Minecraft 26.3

Expanded integration with **Mod Menu 21.0.0**. Experimental beta for **Fabric Loader 0.19.5+** and **Java 25**.

- General, Advanced and About settings tabs, with all seven options, tooltips, validation, save/cancel/reset and Entity Culling status.
- English/Russian mod-card translations, project/source/issue/download/changelog/guide links, the icon, author Nodelll and MIT license.
- GitHub update notifications through Mod Menu, respecting channel preferences and the running Minecraft version. Updates open a release page for manual download.

The default display distance remains **18 blocks**. Existing settings are preserved. **Mod Menu** is optional for configuration and notifications; **Entity Culling** is optional for hiding models behind blocks. Install this JAR on the client and remove the previous mod JAR.

All five automated test suites and the official Mod Menu API smoke check passed. The complete Minecraft GUI and shader/modpack behavior still need an in-game check.
