# Display Model Optimizer 0.7.0 — Minecraft 26.3

**Standalone off-screen display culling**, inspired by the renderer-bounds principle in CullDisplayEntities.

- Minecraft uses cached actual item/block model bounds to skip displays outside the camera view, including entities with zero server width/height.
- New **Hide off-screen models** switch in Mod Menu, enabled by default. It works without Entity Culling.
- Wall occlusion has its own independent switch and uses Entity Culling when installed.
- Large-model extents, translation, negative scale, rotation and conservative interpolation bounds are retained; unchanged poses reuse their immutable AABB.
- Existing seven-option configurations upgrade to eight while retaining preferences and unknown properties. Default distance: **18 blocks**.

Client mod for **Minecraft 26.3**, **Fabric Loader 0.19.5+**, **Java 25**. Optional **Mod Menu 21.0.0** for settings and **Entity Culling 1.11.3** for wall occlusion. Replace the previous mod JAR in the client's `mods` folder.

Six test suites passed, including **236 official Minecraft Frustum checks** and **68 configuration checks**. The mixins also passed transformation and stack verification both without Entity Culling and with its original renderer/extraction hooks. Full in-game/modpack/shader behavior and FPS still need testing.

**Самостоятельное отсечение display-моделей вне кадра** по принципу границ видимости, использованному в CullDisplayEntities.

- Minecraft использует реальные кэшированные границы item_display и block_display, чтобы скрывать модели вне поля зрения камеры, в том числе при нулевых серверных width/height.
- Новый переключатель **«Скрывать модели вне кадра»** находится в Mod Menu и включён по умолчанию; Entity Culling для него не нужен.
- Скрытие за стенами настраивается отдельно и использует установленный Entity Culling.
- Учтены размеры крупных моделей, перенос, отрицательный масштаб, поворот и интерполяция; неизменные границы используются повторно.
- Конфиг автоматически обновляется с семи до восьми параметров с сохранением значений и неизвестных свойств. Дальность по умолчанию — **18 блоков**.

Для **Minecraft 26.3**, **Fabric Loader 0.19.5+** и **Java 25**. **Mod Menu 21.0.0** нужен для интерфейса настроек, **Entity Culling 1.11.3** — для скрытия за стенами. Заменить предыдущий JAR в клиентской папке `mods`.

Шесть наборов тестов, включая 236 проверок настоящего Frustum Minecraft и 68 проверок настроек, прошли. Применение mixin-компонентов проверено без Entity Culling и вместе с его оригинальными хуками. Работу полной сборки, шейдеров и прирост FPS нужно проверить в игре.
