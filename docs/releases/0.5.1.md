# Display Model Optimizer 0.5.1 — Minecraft 26.3

Experimental beta for **Fabric Loader 0.19.5+** and **Java 25**. Install the JAR on the client.

Optimizes `item_display` and `block_display` rendering with frame-local block model caching, faster draw-group lookups and a configurable distance limit of **18 blocks by default**. Set the distance to **0** to retain the original range.

**Entity Culling** is optional and enables occlusion behind blocks. **Mod Menu** is optional and provides the English/Russian settings screen. Settings are stored in `config/display-model-optimizer.properties`.

Automated checks and offline Mixin/API verification have passed. Full in-game behavior and FPS still need validation with the intended modpack and shaders.
