# Display Model Optimizer icon

Created for Display Model Optimizer by Nodelll with the built-in imagegen tool.

The cube represents display models and decorations; the lightning bolt represents rendering performance. The icon has no text so it remains readable in a small Mod Menu row.

The generated PNG was downscaled to 256 × 256 with ImageMagick, preserving transparency. The packaged asset is `src/main/resources/assets/display_model_optimizer/icon.png`; Fabric metadata points to `assets/display_model_optimizer/icon.png` inside the JAR.
