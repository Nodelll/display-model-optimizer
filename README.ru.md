# Display Model Optimizer

**Клиентская оптимизация отрисовки моделей display-сущностей в Minecraft.**

[English](README.md) · [Скачать](https://github.com/Nodelll/display-model-optimizer/releases) · [Сообщить об ошибке](https://github.com/Nodelll/display-model-optimizer/issues) · [Сборки](https://github.com/Nodelll/display-model-optimizer/actions)

Display Model Optimizer сокращает повторную работу при отрисовке `item_display` и `block_display`. Мод подходит для декораций, кастомной мебели, витрин и других мест с большим количеством моделей в одиночных мирах и на серверах.

## Возможности

- **Кэш моделей блоков:** одинаковые поддерживаемые модели готовятся один раз за кадр.
- **Ускоренный поиск групп:** снижаются затраты на группировку моделей для отрисовки.
- **Настраиваемая дальность:** дополнительный лимит отрисовки **18 блоков по умолчанию**.
- **Отсечение вне кадра:** реальные границы моделей позволяют Minecraft скрывать item_display и block_display вне поля зрения камеры; Entity Culling для этого не требуется.
- **Интеграция с Entity Culling:** границы моделей позволяют скрывать display-сущности, полностью закрытые непрозрачными блоками.
- **Интеграция с Mod Menu:** вкладки настроек на русском и английском, ссылки на проект и скачивание, состояние зависимостей и уведомления о совместимых обновлениях GitHub.

## Требования

| Компонент | Версия / назначение |
| --- | --- |
| Minecraft | **26.3** |
| Fabric Loader | **0.19.5 или новее** |
| Java | **25** |
| Entity Culling | Необязателен; нужен для скрытия за блоками. Проверена версия **1.11.3** для Minecraft 26.3. |
| Mod Menu | Необязателен; нужен для экрана настроек. Проверена версия **21.0.0**. |

Мод устанавливается на **клиент**. Кэширование моделей, ускоренный поиск групп и ограничение дальности работают без Entity Culling. Fabric API не входит в зависимости мода.

## Установка и настройки

1. Скачать JAR из раздела [Releases](https://github.com/Nodelll/display-model-optimizer/releases).
2. Удалить предыдущую версию из папки `mods`, поместить туда новый JAR и перезапустить Minecraft.
3. Открыть **Mod Menu → Display Model Optimizer** либо вручную изменить `config/display-model-optimizer.properties` и перезапустить игру.

**Максимальная дальность моделей по умолчанию — 18 блоков.** Параметр `displayRenderDistance` можно увеличить для дальних моделей или установить в **0**, чтобы сохранить исходную дальность игры и сервера. Лимит применяется к `item_display` и `block_display`.

Отсечение вне кадра выполняется обычной проверкой камеры Minecraft и работает без Entity Culling. Новый параметр `cullOffscreenDisplays` по умолчанию включён и настраивается отдельно от `cullOccludedDisplays`. Учитываются реальные размеры, преобразования и интерполяция модели; видимая часть крупной модели сохраняет её отрисовку. Подробнее — в [документации отсечения](docs/CULLING.md).

Для скрытия за блоками используется установленный Entity Culling и его правила прозрачности. Полные непрозрачные блоки закрывают модели; стекло и невидимые барьеры не считаются непрозрачной стеной. Анимированные модели предметов, перемещающиеся display-сущности и модели с неизвестными границами могут оставаться видимыми.

При первом запуске с новым конфигом настройки переносятся из единственного файла `.properties` в папке `config`, содержащего полный набор семи базовых параметров прежних версий. Исходный файл сохраняется, а существующий новый конфиг имеет приоритет. При обновлении до восьми параметров прежние значения сохраняются, а `cullOffscreenDisplays=true` добавляется автоматически. При неоднозначности или неполном наборе параметров нужный файл можно заранее переименовать вручную.

### Mod Menu

На вкладке **«Основное»** находятся переключатели оптимизации и дальность моделей, в **«Дополнительно»** — лимит кэша и параметры индекса групп, в **«О моде»** — версии, наличие Entity Culling и ссылки на проект. У каждого параметра есть подсказка. Черновик сохраняется при переключении вкладок и изменении размера окна до нажатия **«Сохранить»**. **«Отмена»** и Escape закрывают экран без применения; **«Сбросить»** возвращает значения по умолчанию в черновике.

В карточке доступны переведённые название и описание, логотип, автор Nodelll, лицензия MIT, значок клиентского мода, сайт, исходники, сообщения об ошибках, скачивание, история изменений и инструкция. Проверка обновлений использует публичные релизы GitHub, отбирает JAR для запущенной версии Minecraft и учитывает включение проверки и канал обновлений в самом Mod Menu. При выборе обновления открывается страница релиза; автоматической установки нет. Отсутствие сети и ограничения API не мешают игре. Подробнее — в [документации интеграции](docs/MOD_MENU.md).

## Сборка из исходников

Установить JDK 25 и Python 3, затем выполнить:

```sh
python3 build.py
```

Скрипт загружает зависимости с проверкой контрольных сумм, компилирует мод, запускает автоматические проверки и сохраняет JAR в `build/libs/`. Minecraft и сторонние библиотеки в готовый мод не включаются.

Путь к конкретному исполняемому файлу Java можно указать через `DISPLAY_MODEL_OPTIMIZER_JAVA`. При установленном Gradle и Java 25 также доступна команда `gradle build`.

## Состояние и проверки

Это **экспериментальная бета-версия**. Автоматические проверки охватывают поиск групп, независимость и время жизни кэшей, перенос настроек, расчёт границ моделей и сцены на настоящем движке Entity Culling. Переименованные mixin-компоненты также применены к официальным классам Minecraft 26.3 совместно с оригинальными mixin-компонентами Entity Culling.

Эти проверки не заменяют запуск Minecraft и замер FPS в реальной сцене. Работу полной сборки и шейдеров нужно проверять в игре. Доступны [заметки о проверках](docs/TESTING.md), [результаты](VALIDATION.json) и [техническая документация](docs/DEVELOPMENT.ru.md).

## Прозрачность разработки

Код, документация, переводы и логотип создавались с использованием генеративного ИИ. Во время игры мод не использует ИИ. Исходники открыты для проверки и доработки.
